# Правила дальнейших обновлений Мразика

Пользователь требует сохранять прогресс питомцев и существующие Discord-роли при обновлениях.

- По умолчанию используйте прежний `DATABASE_PATH=data/gnid.sqlite3`. Не создавайте новую пустую базу под новым именем при смене версии или имени персонажа.
- Каждая миграция должна иметь постоянный ключ в `migrations`, быть повторяемой без изменения уже перенесённых данных и проходить тест на повторный запуск.
- Не сбрасывайте users.xp, coins, outfit, owned, personal_pets, quiz_seen, settings, rank_roles и role_settings при старте, обновлении контента или синхронизации команд.
- users.xp — единственный источник опыта личного питомца. users.outfit — его выбранный образ. Не создавайте второй независимый счётчик опыта для питомца.
- Уход и одежда всегда адресуются парой (guild, uid). Общая таблица pets — только архив прежней версии, живой код её больше не обновляет.
- Не создавайте и не переименовывайте Discord-роли при запуске. Используйте сохранённые ID rank_roles. Создание — только по явной команде модератора /роли_настроить.
- Повышение питомца может менять только сохранённые роли рангов этого участника. Остальные роли не трогайте. Не меняйте прежние пороги рангов без явного запроса пользователя и отдельной миграции.
- Сохраняйте постоянные ID кнопок, ключи костюмов и вопросы в истории при добавлении контента.
- Перед миграцией существующих данных делайте согласованную резервную копию через SQLite backup API. Копия рядом с базой не заменяет внешнюю копию владельца.
- Обычные игры ограничены игровым каналом. По явному запросу пользователя версия 4 разрешает автоматический сундук в случайном открытом текстовом канале (@everyone видит канал, бот имеет права). Другие публикации остаются в игровом канале. Личные игры и инвентарь — ephemeral.
- В архив обновления не включайте .env с токеном, базу, data/, backups/, .venv или __pycache__.
- Перед поставкой выполните тесты миграции/разделения питомцев, тесты ролей и check_discord.py. В описании укажите, установлен ли код на живом хостинге.

- Архив обновления содержит только изменённые файлы; в assets включать только новые/изменённые изображения. Прежние изображения остаются в репозитории.
- Версия 4.1 по запросу владельца убирает дневной лимит монет/XP. Паузы игр, история вопросов и защита от двойной награды сохраняются. Рангов десять; первые шесть порогов/названий/ID сохраняются.

- Версия 4.2 по запросу владельца расширяет исключение открытых каналов на случайные иллюстрированные события. Планировщик Roaming независим от часовых игр; не запускать старый tick_drops параллельно.

- Версия 4.3 отменяет прежнее исключение случайных открытых каналов по запросу владельца. ВСЕ автопосты направляются только в settings.channel, выбранный через /настройка. При недоступности этого канала запрещён переход на другой.

- Версия 5: ежедневный босс публикуется только в settings.channel. Сохраняйте boss_settings, boss_runs и boss_hits при обновлении. Один бой на (guild, day), пауза удара на (boss, uid) — 3600 секунд. Награды всем участникам и закрытие боя должны фиксироваться одной транзакцией; повторный удар не может повторить выплату. Существующие ранги и дневные лимиты не менять.
