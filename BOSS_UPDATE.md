# Мразик 5 — ежедневный босс

## Установка обновления

1. Сделайте внешнюю резервную копию действующей базы `data/gnid.sqlite3` на Bothost (или файла из DATABASE_PATH). Не удаляйте её и не меняйте DATABASE_PATH; база должна храниться в постоянном хранилище хостинга.
2. Распакуйте архив. Загрузите его содержимое в корень существующего GitHub-репозитория, заменив одноимённые файлы. Папку tests загрузите как папку. Сам ZIP загружать не нужно. Старые файлы и assets оставьте: используются уже существующие изображения dragon, lich, demon, mushroom.
3. Выполните обновление из репозитория и пересборку на Bothost. Простой перезапуск старого образа не заберёт новый код. В логах должна появиться строка `Mrazik build 5: daily cooperative boss, persistent hourly attacks`.
4. Проверьте `/босс`. Новая кнопка «Босс дня» появится в заново открытом главном меню. Старую постоянную панель можно заново опубликовать командой `/панель`.

Код ещё не установлен на вашем хостинге: архив нужно загрузить и пересобрать самостоятельно.

## Запуск и команды

Босс включён по умолчанию для серверов с настроенным игровым каналом. Он появляется ежедневно в 12:00 по TZ бота (по умолчанию Europe/Moscow). Если обновление запущено после 12:00, сегодняшний босс появится на ближайшей проверке — обычно до 30 секунд. Публикация идёт только в канал, выбранный через `/настройка`. При ошибке отправки повторная попытка через пять минут; другой канал не выбирается.

Игрокам доступны `/босс`, кнопка «Босс дня», «Ударить босса», «Мой вклад». Ответы об ударе и вкладе видит только сам игрок.

Владелец сервера или участник с правом «Управлять сервером» может выполнить:

- `/босс_настройка включить:True час:12 здоровье:1500` — расписание и здоровье следующих боссов.
- `/босс_призвать` — начать сегодняшний бой сейчас, не дожидаясь часа появления. Второго босса за тот же день не создаёт, даже после победы. Эта явная команда работает и при выключенном расписании.
- `/босс_настройка включить:False` — остановить будущие появления; уже начатый бой продолжается.

Боту нужны права «Просматривать канал», «Отправлять сообщения», «Встраивать ссылки», «Прикреплять файлы». Для удаления своих сообщений право «Управлять сообщениями» не требуется. Имеющиеся права выдачи рангов остаются прежними.

## Правила боя

- У босса по умолчанию 1500 HP; четыре случайных образа с существующими картинками.
- Каждый участник наносит 80–140 урона раз в 60 минут. Отсчёт индивидуальный, от последнего удара по этому боссу.
- Бой продолжается до полуночи по TZ бота. Если босс выжил, он сбегает без наград. Пропущенные дни не накапливаются.
- При победе каждый, кто нанёс хотя бы один удар, автоматически получает 100 монет и 60 опыта плюс бонус за долю нанесённого урона: floor(300 × урон / здоровье босса) монет и floor(180 × урон / здоровье босса) опыта. Например, при вкладе 10% — 130 монет и 78 опыта.
- Награда начисляется и отсутствующим в сети участникам; повторно забирать её не нужно. Последний удар не получает отдельного бонуса. Урон сверх оставшегося здоровья не засчитывается.
- Дневного лимита монет и опыта нет. За отдельный удар до победы награды нет.
- Публичная карточка обновляется на месте и удаляется через час после завершения. Кнопка возврата ведёт в личное меню, не засоряя канал.
- База сохраняет HP, вклад, таймеры и выплаты. Обновление не сбрасывает питомцев, одежду, деньги или роли. Повышение ранга использует существующую очередь ролей.

При проблемах `/босс` показывает состояние и последнюю ошибку публикации. Административные команды доступны владельцу или обладателю права «Управлять сервером»; обычным участникам это право для игры не требуется.
