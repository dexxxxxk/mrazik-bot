# Отдельный чат и роли за опыт питомца

## 1. Игровой чат

Создайте обычный текстовый канал, например **#мразик**.

В его настройках откройте «Права доступа», выберите роль бота Мразик и разрешите:

- Просматривать канал (View Channel).
- Отправлять сообщения (Send Messages).
- Встраивать ссылки (Embed Links).
- Прикреплять файлы (Attach Files).
- Читать историю сообщений (Read Message History).

Для игроков разрешите просмотр канала и использование команд приложений (Use Application Commands). Если хотите, чтобы люди также общались, разрешите отправку сообщений.

В Discord выполните `/настройка`, в параметре **канал** выберите **#мразик**, затем отправьте `/панель` в этом канале. Смена канала не меняет питомцев, опыт, вещи и роли.

Публичные события, дуэли, звания и задания теперь идут только в выбранном канале. При вызове игры в другом канале бот покажет только вызвавшему сообщение «Играем в #мразик». Справка и некоторые административные команды могут отвечать вне игрового канала, тоже приватно. До настройки канала игры не публикуются вообще.

Дополнительное ограничение Discord: в других каналах/категориях можно запретить роли бота «Просматривать канал». В #мразик оставьте явное разрешение и проверьте, что права категории не скрыли его. Administrator боту не нужен: он обходил бы ограничения каналов. [Настройка прав каналов — Discord](https://support.discord.com/hc/en-us/articles/206029707-Setting-Up-Permissions-FAQ).

## 2. Право выдавать роли

Откройте **Настройки сервера → Роли → роль бота Мразик → Права доступа**.

1. Включите **Управлять ролями (Manage Roles)**.
2. Сохраните изменения.
3. В списке ролей перетащите роль Мразика **выше всех шести игровых рангов**.

Право Manage Roles работает с ролями ниже роли бота в иерархии. Administrator, блокировка участников и управление каналами для этого не требуются. [Роли и иерархия — Discord](https://support.discord.com/hc/en-us/articles/214836687-Discord-Roles-and-Permissions).

Первый запуск: выполните **`/роли_настроить`**. Бот создаст шесть ролей без серверных прав и включит выдачу. Команду выполняет владелец сервера или модератор с правом «Управлять сервером».

Если роли уже создавались в версии 2/2.1 и база сохранена, просто используйте **`/роль`** для проверки. После обычного обновления запускать настройку повторно не требуется. Отключённые автороли включаются через `/автороли включить:True`.

Не удаляйте созданные роли и не добавляйте им серверные права. Бот хранит их ID и выдаёт только эти игровые роли. Если он отказывает из-за иерархии, поднимите его роль выше рангов и повторите `/роль`.

## 3. Как работает прокачка

У каждого участника **один личный Мразик** на сервере. `/мразик` открывает своего питомца. Кнопки кормления, игры и сна меняют только его состояние. `/гардероб` и `/одеть` переодевают только его.

Опыт из ежедневного визита, ухода, викторин, игр и одобренных заданий — это опыт своего питомца. Старый личный опыт из предыдущих версий уже входит в него. Роль выдаётся владельцу:

| Опыт питомца | Роль владельца |
|---:|---|
| 0 | Подзаборный шнырь |
| 150 | Мелкий пакостник |
| 450 | Штатная мразота |
| 1000 | Помойный авторитет |
| 2000 | Барон Логова |
| 4000 | Легендарная мразь |

После получения опыта роль обычно обновляется в пределах минуты, при большой очереди — дольше. `/роль` запускает проверку сразу. Старый игровой ранг снимается, новый добавляется; остальные роли участника остаются.

Проверка: `/мразик` → `/ежедневно` → `/мразик` → `/роль`. Питомец получит 20 XP за ежедневный визит, если награда сегодня ещё не забрана. До порога 150 роль останется начальной — это правильно.

## 4. Не потерять прогресс при обновлении

Прогресс находится в SQLite, а не в GitHub. Оставляйте прежние `DATABASE_PATH` и постоянную папку данных на хостинге. Загружайте только исходники и рисунки. Резервную копию данных держите отдельно от хостинга.

Версия 3 использует миграцию с отметкой выполнения: повторный запуск не создаёт питомца заново, не сбрасывает его опыт и одежду, не пересоздаёт Discord-роли. Правила для дальнейших изменений записаны в `AGENTS.md`, а поведение проверяется тестами.
