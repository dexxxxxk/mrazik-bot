# Мразик 4.3 — один канал для автопостов

Обновление поверх версии 4.2.1. Архив содержит только изменённые файлы; картинки повторно загружать не нужно.

1. Сохраните копию данных бота. Распакуйте архив и загрузите содержимое в прежний репозиторий с заменой. Остальные файлы и assets не удаляйте.
2. Получите обновление и пересоберите существующего бота на Bothost. Лог: Mrazik build 4.3: autoposts only in configured game channel.
3. После обновления все новые автопосты автоматически используют игровой канал, ранее выбранный через /настройка. Включать их заново не нужно, если они уже включены.
4. Если нужен другой отдельный чат, владелец сервера выбирает его в /настройка канал:#мразик. Это также меняет канал обычных игр и ежедневного задания. Параметры час и автопост этой команды относятся к ежедневному заданию: задайте их прежние значения, если оно использовалось.
5. На панели нажмите «Автопосты: проверка»: она покажет единственный канал. Для немедленной проверки — «Событие сейчас». Управляет владелец или участник с правом «Управлять сервером».

Все четыре случайных события, прежние часовые игры и ежедневное задание идут в один игровой чат. Расписание и включённость сохраняются. Если канал удалён или боту не хватает прав, автопост не отправляется в другой канал; причина отображается в диагностике. Канал для случайных событий должен оставаться видимым @everyone, боту нужны просмотр, отправка сообщений, встраивание ссылок и прикрепление файлов.

Уже опубликованная до обновления карточка в другом канале может оставаться до завершения её срока. Новые посты туда не отправляются.

База, токен, DATABASE_PATH, GUILD_ID, роли, монеты, питомцы и инвентарь остаются прежними. Прошли 85 тестов, check_discord.py и check_sync.py. Проверены отсутствие отправки в другой доступный канал и смена назначения через /настройка. На живой хостинг обновление автоматически не установлено.
