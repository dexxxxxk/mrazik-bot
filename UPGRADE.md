# Мразик 4.1 — обновление поверх версии 4

В этом небольшом архиве только изменённые файлы. Картинок нет: прежнюю папку assets оставьте в репозитории.

1. Сохраните резервную копию существующей папки данных бота. Базу, DATABASE_PATH и токен не меняйте.
2. Распакуйте архив. Загрузите содержимое в корень прежнего репозитория с заменой одноимённых файлов. Остальные файлы и папки не удаляйте.
3. На Bothost получите новый код и пересоберите существующего бота. В логах: `Mrazik build 4.1: no daily reward cap, 10 ranks`.
4. В Discord выполните `/роли_настроить`. При сохранённых шести старых ролях создадутся только четыре новые. Повторный запуск команды не создаёт дубликаты сохранённых ролей.
5. Роль бота должна быть выше всех десяти рангов; право «Управлять ролями» должно быть включено. Существующий XP учитывается, роли выдаются очередью. Для проверки — `/роль` и `/ранги`.
6. `/награды` покажет отсутствие дневного лимита. До добавления новых ролей прежние шесть продолжают работать.

Новые ранги:

| XP | Ранг |
|---:|---|
| 7000 | Повелитель зловония |
| 11000 | Владыка помойных миров |
| 17000 | Древнее зло Логова |
| 25000 | Абсолютная мразота |

Все старые пороги, названия и сохранённые ID ролей остаются прежними. Схема базы не меняется; XP, монеты, питомцы, инвентарь и одежда не сбрасываются.

Лимит 300 монет/200 XP убран, в том числе для уже достигших его сегодня. Прошлые неполученные награды автоматически не компенсируются. Паузы между играми, одна награда за событие, ежедневная подачка и до трёх личных новых вопросов викторины в сутки сохраняются. Неверный ответ по-прежнему может дать 0 монет.

Проверены 77 тестов и check_discord.py (35 команд, меню, изображения). На живой Bothost этот архив автоматически не установлен.
