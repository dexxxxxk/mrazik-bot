# Обновление до Мразика 4 на Bothost

Это полный комплект кода и изображений. На живой хостинг он автоматически не установлен.

1. Остановите бота на Bothost и скачайте копию его текущей папки данных целиком: база `gnid.sqlite3` и сопутствующие файлы. Если задан другой DATABASE_PATH, используйте фактическую папку. Убедитесь, что эта папка сохраняется при пересборке контейнера; данные только внутри временного контейнера могут исчезнуть при деплое.
2. Распакуйте архив на Windows. В GitHub загрузите содержимое архива в корень существующего репозитория с заменой одноимённых файлов. `bot.py`, `features.py`, `game.py`, новые `adventures.py`, `expansion.py`, `collection.py` и папка `assets/` должны оказаться рядом. ZIP-файл целиком в репозиторий загружать не нужно. Папку `assets/` обновите со всеми новыми PNG.
3. Сохраните изменения в прежней ветке, которую использует Bothost. Не удаляйте репозиторий и не создавайте нового бота.
4. На Bothost получите изменения из репозитория и пересоберите/разверните существующего бота. Один перезапуск без получения нового кода не обновляет файлы.
5. Оставьте прежние токен, GUILD_ID, DATABASE_PATH, настройки Dockerfile и постоянную папку данных. Не заменяйте базу пустой и не публикуйте её или токен в GitHub.
6. В логах должна появиться строка `Mrazik build 4: inventory, maze, auto rewards, 20 new outfits`.
7. Проверьте прежний баланс `/профиль`, питомца `/мразик`, роли `/роль`. Откройте `/инвентарь`, `/лабиринт` и `/альбом`. Новые образы доступны через подсказки при вводе названия.
8. В игровом канале можно один раз опубликовать новую `/панель` и вручную удалить старую, чтобы видеть новые кнопки. Повторно запускать `/роли_настроить` для уже настроенных ролей не требуется.

Часовые игры включаются `/события включить:True`. Случайные коллекционные сундуки включены по умолчанию, первый появляется через 2–4 часа. Выключение: `/сундук_события включить:False`. Каждый участник забирает один сундук за 5-минутное событие; открывает позже в `/инвентарь`.

При первой миграции существующей базы код делает SQLite-backup в `backups/` рядом с ней. Это дополнительная копия, а не замена внешней резервной копии перед пересборкой. XP, монеты, купленные/надетые вещи, личные питомцы, история вопросов и ID ролей не сбрасываются. В архиве базы и токена нет.

Для отката сначала остановите бота. Старый код не знает названий новых костюмов, поэтому откат к старому коду требует согласованной копии базы до обновления; прогресс после этой копии будет утрачен. Не откатывайте только Python-файлы поверх данных с новыми образами.
