# Мразик 4.1 — коллекция и лабиринт

Discord-бот «Мразотного Логова»: личный питомец каждому игроку, одежда, опыт, монеты, ранги и игры. 35 команд, 32 образа питомца и 4 изображения состояний.

## Что нового

- 20 новых цельных рисунков в прежнем мультяшном стиле: 10 покупаемых образов и 10 редких из коллекционных сундуков. Все фоны непрозрачные.
- `/лабиринт`: личное поле 9×9, стрелки движения, случайный связный маршрут. На поход 10 минут, за выход 40 монет и 25 XP без дневного лимита. Можно вернуться в меню и продолжить незавершённый поход.
- Автоматические часовые викторины и кликалки дают монеты и XP сверх дневного лимита. Повторно получать награду с одного события нельзя. История вопросов сохраняется.
- Раз в случайные 2–4 часа Мразик оставляет коллекционный сундук в случайном открытом текстовом канале. Каждый участник может забрать один сундук за событие; окно — 5 минут. Публикации без массовых упоминаний.
- `/инвентарь`: сундуки можно хранить и открывать позже. 20% — один из 10 редких образов; 80% — 50–120 монет и 15–35 XP. Повтор редкого образа заменяется на 150 монет и 40 XP. Эти награды сверх лимита.
- Личные игры и основные карточки обновляют приватное сообщение при переходах с кнопок. «В меню» возвращает к действиям. Завершённые общие события бот удаляет при следующей фоновой проверке, обычно до 30 секунд после окончания. Панель и задание дня не удаляются.

Это игра с кнопками Discord. Полноценной 3D-игры в этой версии нет.

## Сохранение данных и обновление

**Сначала прочитайте `UPGRADE.md`.** Существующие XP, монеты, костюмы, питомцы, история вопросов, настройки и ID ролей сохраняются в прежней базе. Новый код добавляет таблицы инвентаря, лабиринтов и расписания сундуков. Перед первой миграцией существующей базы создаётся SQLite-backup рядом с ней.

Сохранность после пересборки контейнера зависит от постоянной папки данных на хостинге. Оставьте прежний `DATABASE_PATH` (по умолчанию `data/gnid.sqlite3`), сохраните внешнюю копию данных. Код не создаёт и не переименовывает Discord-роли при старте.

## Запуск

Главный файл: `bot.py`. Dockerfile использует Python 3.12. Зависимости: `requirements.txt`.

Переменные окружения:

```dotenv
DISCORD_TOKEN=ваш_токен
GUILD_ID=ID_сервера
TZ=Europe/Moscow
DATABASE_PATH=data/gnid.sqlite3
```

Оставьте прежние значения у работающего бота. Токен и базу в GitHub не загружайте. Для локального запуска скопируйте `.env.example` в `.env` и заполните его.

Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Docker с постоянной папкой `data/` через комплектный Compose:

```bash
docker compose up -d --build
```

Один токен — один запущенный экземпляр бота.

## Настройка в Discord

1. Для нового сервера: `/настройка канал:#мразик`, затем `/панель` в игровом канале. Если сервер уже настроен, настройки сохранятся.
2. Часовые игры: `/события включить:True`. Тихие часы задаются там же. Награды автоматических событий теперь не ограничены дневным лимитом.
3. Случайные коллекционные сундуки включены по умолчанию для настроенного сервера, первый — через 2–4 часа. Выключение: `/сундук_события включить:False`. Это отдельное расписание; тихие часы часовых игр на него не действуют.
4. Канал для сундука должен быть виден роли `@everyone`. Боту нужны «Просматривать канал», «Отправлять сообщения», «Встраивать ссылки», «Прикреплять файлы», «Читать историю сообщений». Закрытые каналы не выбираются; форумы, ветки и голосовые каналы также не выбираются.
5. Для выдачи рангов боту нужно «Управлять ролями», а его роль должна стоять выше всех десяти игровых рангов. Первичная настройка — `/роли_настроить`; уже настроенные роли повторно создавать не нужно. `/роль` проверяет свой ранг. Подробности: `DISCORD_SETUP.md`.

Обычные игры остаются в игровом канале. Исключение — случайный сундук в открытом канале. Инвентарь можно открыть приватно из любого канала сервера.

В `/альбом` начинайте вводить название: подсказки ищут среди всех 36 картинок. Гардероб с более чем 25 вещами показывает несколько меню выбора. Редкую одежду нельзя купить за нулевую цену — только получить из сундука.

`/сундуки` — старая игра «выбери один из трёх», она не расходует предметы. `/инвентарь` — новые сохранённые коллекционные сундуки.

## Правила и проверки

Дневной лимит монет и XP снят для всех игр и ухода. `/награды` показывает баланс и правила начисления. Автопосты, коллекционные сундуки, подачка дня и одобренные творческие задания идут сверх лимита. Повтор вопроса или неверный ответ не превращается в выигрыш из-за отмены лимита.

```bash
python -m unittest discover -s tests -q
python check_discord.py
```

Проверены сохранение данных и ролей, защита от двойной выдачи, чужого сундука и чужого лабиринта, награды после лимита, навигация и удаление событий. `check_discord.py` проверяет регистрацию 35 команд, меню и наличие 36 изображений без подключения к Discord. Живой хостинг этим архивом ещё не обновлён.
