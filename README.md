# Гнидь — бот «Мразотного Логова»

Готовый исходный комплект первой версии: 22 команды, общий питомец, личная коллекция костюмов, игры и 11 изображений. Бот ещё не подключён к вашему серверу. Для запуска нужен ваш Discord Bot Token и компьютер или сервер, который будет оставаться включённым.

## Что внутри

| Раздел | Возможности |
|---|---|
| Гнидь | Общие сытость, настроение, энергия, опыт и выбранный костюм; кормление, игры, сон |
| Участники | Монетки, 6 рангов, серия ежедневных визитов, 5 достижений |
| Одежда | 6 покупных костюмов + исходный образ, личный гардероб и переодевание общего питомца |
| Игры | 30 вопросов викторины, тайные дуэли «камень-ножницы-бумага», экспедиции |
| Жизнь сервера | 14 заданий дня, проверка модератором, добровольные шуточные звания, недельный и общий рейтинг |
| Характер | Русские реплики, предсказания и иллюстрации состояний |
| Управление | Отдельный игровой канал, постоянная панель с кнопками, необязательный автопост задания |

Все изображения находятся в `assets/`. Посмотреть их в Discord без покупки можно через `/альбом`. Полные правила и баланс — в `DESIGN.md`.

## 1. Создать бота в Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications), создайте приложение и назовите его «Гнидь».
2. В разделе **Bot** задайте имя и аватар. Для аватара используйте `assets/base.png`. Получите токен через **Reset Token** и сохраните его только в своём `.env`.
3. В **Installation** разрешите **Guild Install**. Для установки выберите scopes `bot` и `applications.commands`.
4. Дайте права **View Channels**, **Send Messages**, **Embed Links**, **Attach Files**, **Read Message History**. Право Administrator для этого кода не требуется.
5. Откройте ссылку установки и выберите свой сервер. Вы должны иметь право устанавливать приложения на нём.
6. В настройках Discord включите режим разработчика, затем скопируйте ID сервера через его контекстное меню.

Бот работает через slash-команды. Привилегированные Message Content Intent, Server Members Intent и Presence Intent включать не нужно. Поле Interactions Endpoint URL оставьте пустым: используется Gateway.

Порядок регистрации основан на [официальной инструкции Discord](https://docs.discord.com/developers/quick-start/getting-started) и [руководстве discord.py](https://discordpy.readthedocs.io/en/stable/discord.html).

## 2. Заполнить настройки

Распакуйте архив. Скопируйте `.env.example` в `.env` внутри папки `gnid-bot` и заполните:

```dotenv
DISCORD_TOKEN=ваш_токен_только_здесь
GUILD_ID=числовой_ID_вашего_сервера
TZ=Europe/Moscow
DATABASE_PATH=data/gnid.sqlite3
```

Не присылайте токен в чат и не публикуйте `.env`. В комплекте нет настоящих ключей. Если токен раскрыт, сбросьте его в Developer Portal.

`GUILD_ID` ускоряет регистрацию команд на одном сервере. Для установки на несколько серверов можно оставить его пустым; глобальные команды появляются не мгновенно. Не переключайте способы регистрации без необходимости: старые команды другого scope автоматически не удаляются.

## 3. Запуск на Windows

Установите Python 3.11 или 3.12 с добавлением в PATH. Откройте терминал в распакованной папке `gnid-bot`:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe check_discord.py
.\.venv\Scripts\python.exe bot.py
```

Первый запуск требует интернета для установки зависимостей. Пока терминал и компьютер работают, бот онлайн. При повторном запуске нужна только последняя команда.

## 3а. Запуск на macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python check_discord.py
.venv/bin/python bot.py
```

## 3б. Работа круглосуточно через Docker

На машине с Docker Compose, из папки проекта и после заполнения `.env`:

```bash
docker compose up -d --build
docker compose logs -f
```

Остановить:

```bash
docker compose down
```

Данные сохраняются в папке `data/` на хосте. Запускайте только один экземпляр этого бота на одном токене. Хост должен иметь исходящий доступ к Discord и постоянный диск; обычный статический хостинг не подходит.

## 4. Первый запуск в Логове

1. Создайте текстовый канал, например `#гнидь`.
2. Выполните `/настройка`, выберите канал. Автопост по умолчанию выключен; при желании включите и задайте час. Часовой пояс берётся из `.env`.
3. В игровом канале выполните `/панель` и закрепите сообщение вручную.
4. Проверьте `/ежедневно`, `/профиль`, `/гнидь`, `/альбом` и `/викторина`.
5. С другом проверьте `/дуэль`: второй участник принимает вызов, затем оба нажимают жест.
6. Для шуточных званий каждый желающий включает `/участие`. Команда `/кто` выбирает одного участника на день.
7. Творческие работы идут через `/сдать`; модератор открывает `/заявки`, затем `/проверить`. Модератору нужно право «Управлять сервером»; свою работу он одобрить не может.

До `/настройка` команды доступны в текстовых каналах сервера. После неё обычные игры ограничиваются выбранным каналом. Большинство ответов видно только нажавшему участнику, а дуэли, панель и звание дня публикуются в канале. Бот не рассылает личные сообщения и не делает пинги.

## Сохранение и обслуживание

- Балансы, вещи, ранги, состояние Гнидя, кулдауны и заявки сохраняются в SQLite. Картинки заявок сохраняются рядом с базой в `data/submissions/`; они не зависят от срока действия Discord CDN-ссылки.
- Для простой резервной копии остановите бота и скопируйте **всю папку `data/`**. После копирования запустите снова. Храните резервные копии отдельно от хоста.
- Панель и постоянные кнопки питомца переживают перезапуск. Незавершённые викторины и дуэли после перезапуска нужно открыть заново; ставки не снимаются. В обычной работе кнопки игр отключаются по тайм-ауту.
- При автопосте бот отправляет одно задание в выбранный день после заданного часа. После простоя прошлые дни не догоняет. Если отправка завершилась сетевой ошибкой, автоматического повтора в тот же день нет, чтобы не получить дубль; задание доступно через `/задание`.
- Удаление заявки/данных по запросу участника выполняет владелец базы вручную. Команды автоматического удаления и срок хранения вложений в этой версии не реализованы. Не держите ненужные старые вложения бесконечно.
- Костюмы показаны в сообщениях бота. Глобальный аватар аккаунта и Discord-роли участников автоматически не меняются. Одежда в этой версии — цельные комплекты, а не послойный конструктор.

Проверено в среде сборки: **19 тестов игрового движка прошли**, синтаксис Python проверен, 11 PNG успешно открываются. Тесты покрывают повторные выплаты и покупки, одновременные запросы, границы суток и недель, сохранение после перезапуска, права владения костюмами, модерацию, лимиты и разделение серверов.

```bash
python -m unittest discover -s tests -v
python check_discord.py
```

Вторая команда дополнительно проверяет регистрацию объектов команд, кнопок и изображений без входа в Discord, но требует установленных зависимостей. **В среде сборки она не запускалась:** установка discord.py была недоступна из-за сетевых ограничений. Живые ответы Discord и сборка Docker здесь не проверены. Выполните её после установки, затем короткий сценарий первого запуска выше.

Версии основных зависимостей закреплены в `requirements.txt`: [discord.py 2.7.1](https://pypi.org/project/discord.py/2.7.1/) и [python-dotenv 1.2.2](https://pypi.org/project/python-dotenv/1.2.2/). Официальная справка по [slash-командам и кнопкам](https://discordpy.readthedocs.io/en/stable/interactions/api.html).

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Бот офлайн | Терминал/контейнер работает, `.env` заполнен, токен актуален |
| Команд нет | ID сервера, scopes установки, ошибки синхронизации в логе; обновите клиент Discord |
| Картинок нет | Папка `assets/` на месте, есть Attach Files и Embed Links |
| Ответ «Играем в…» | Перейдите в выбранный канал или смените его через `/настройка` |
| Награда 0 | Достигнут дневной игровой лимит |
| Заявки не видны | Для модерации нужно Manage Server / «Управлять сервером» |
| `ZoneInfoNotFoundError` | Установите все зависимости, включая `tzdata`, проверьте `TZ` |

Контент и цены можно менять в `content.py`, расчёты — в `game.py`, команды и оформление — в `bot.py`.
