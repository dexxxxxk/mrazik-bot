# Мразик — «Мразотное Логово», версия 2.1

31 slash-команда, общий питомец, 12 образов для гардероба и 4 изображения состояний, Discord-роли за личный опыт, случайные часовые события и игры. Все рисунки уже включены; платный ИИ для работы не нужен.

**Если бот уже работает, начните с `UPGRADE.md`.** Обновление использует существующую SQLite-базу: баланс, опыт, костюмы и настройки сохраняются, если хост сохраняет файл базы. Имя базы `data/gnid.sqlite3` намеренно оставлено прежним.

## Что нового

- Персонаж и команда питомца называются **Мразик**, `/мразик`.
- Шесть Discord-ролей по личному опыту. Команда `/роли_настроить` создаёт роли и учитывает старый опыт.
- В настроенном игровом канале примерно раз в час случайно появляется викторина, заначка или «Поймай пакость». Событие длится 5 минут; каждый участник получает одну попытку.
- Личные игры `/сундуки`, `/угадай`, `/рыбалка` дополняют викторину, дуэли и экспедиции.
- Пять новых костюмов: пляжный, пират, вампир, кибермразь, космонавт. Просмотр `/альбом`, покупка `/магазин`.
- Постоянная кнопка **«Все команды»** открывает справку с разделами и описанием каждой команды. Кнопка **«Больше игр»** открывает игровой раздел.

Часовые события включены по умолчанию после `/настройка`. Первая игра — через 5–55 минут; далее случайная минута каждого следующего часа. Включение, выключение и тихие часы: `/события`. Задание дня имеет отдельный автопост, который по умолчанию выключен.

## Настройки и первый запуск

1. Создайте приложение «Мразик» в [Discord Developer Portal](https://discord.com/developers/applications). В разделе Bot задайте имя и аватар, получите Bot Token.
2. Установите бота на сервер с scopes `bot` и `applications.commands`. Нужны права: View Channels, Send Messages, Embed Links, Attach Files, Read Message History. Для рангов дополнительно Manage Roles; для изменения своего ника — Change Nickname. Administrator не требуется.
3. Скопируйте `.env.example` в `.env`, заполните `DISCORD_TOKEN` и при необходимости `GUILD_ID`. На хостинге используйте переменные окружения. Настоящий `.env` с токеном в GitHub не загружайте.
4. Установите Python 3.11 или 3.12 и зависимости. Главный файл — `bot.py`.

```dotenv
DISCORD_TOKEN=ваш_токен
GUILD_ID=числовой_ID_сервера
TZ=Europe/Moscow
DATABASE_PATH=data/gnid.sqlite3
```

Windows PowerShell, из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe check_discord.py
.\.venv\Scripts\python.exe bot.py
```

Linux/macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python check_discord.py
.venv/bin/python bot.py
```

Docker, после заполнения `.env`:

```bash
docker compose up -d --build
docker compose logs -f
```

Папка `data/` смонтирована на постоянный диск в комплектном Compose. При другом способе запуска настройте постоянное хранение этой папки на хостинге. Запускайте один экземпляр бота на одном токене.

Привилегированные Message Content, Members и Presence Intents не нужны. Interactions Endpoint URL не заполняется: бот подключается через Gateway. `GUILD_ID` регистрирует команды для одного сервера; пустое значение — глобально. При обновлении сохраняйте прежнее значение, чтобы не получить команды двух разных областей регистрации.

## Настройка внутри Discord

1. `/настройка` — выбрать игровой текстовый канал. При желании включить отдельный автопост задания дня.
2. `/панель` — опубликовать и закрепить новое меню.
3. В настройках сервера дайте роли Мразика **«Управлять ролями»** и расположите её выше игровых рангов.
4. `/роли_настроить` — создать шесть ролей. Старые участники получат ранг по накопленному опыту через очередь; новые — после первой награды или `/роль`.
5. `/событие` — проверить общее событие сейчас. `/события включить:True тихо_с:23 тихо_до:8` — задать ночную паузу. Одинаковые часы означают отсутствие паузы.
6. `/мразик`, `/сундуки`, `/рыбалка`, `/альбом` — проверить новые возможности.

Бот старается поставить себе серверный ник «Мразик». Если нет права менять ник, задайте его вручную. Старые сообщения в истории и название приложения в Developer Portal код не переписывает.

## Команды

Полный справочник с параметрами доступен по кнопке **«Все команды»** и через `/помощь`.

| Раздел | Команды |
|---|---|
| Начало | `/помощь`, `/профиль`, `/ежедневно`, `/мразик` |
| Игры | `/викторина`, `/дуэль`, `/экспедиция`, `/предсказание`, `/сундуки`, `/угадай`, `/рыбалка` |
| Коллекция | `/магазин`, `/гардероб`, `/одеть`, `/ранги`, `/альбом`, `/роль` |
| Компания | `/участие`, `/кто`, `/топ`, `/задание`, `/сдать`, `/байка` |
| Модераторы | `/настройка`, `/панель`, `/заявки`, `/проверить`, `/роли_настроить`, `/автороли`, `/события`, `/событие` |

Модераторские команды требуют «Управлять сервером». Для обычных игр используется выбранный игровой канал. Большинство личных ответов видно только вызвавшему команду. Публичные события, дуэли и панель видны всем в канале; пинги и личные рассылки не отправляются.

## Опыт, роли и награды

| Личный опыт | Discord-роль |
|---:|---|
| 0 | Подзаборный шнырь |
| 150 | Мелкий пакостник |
| 450 | Штатная мразота |
| 1000 | Помойный авторитет |
| 2000 | Барон Логова |
| 4000 | Легендарная мразь |

У участника одна роль ранга: при повышении предыдущая снимается. Остальные роли не меняются. Бот создаёт отдельные роли без серверных прав и запоминает их ID; существующие одноимённые роли он не присваивает автоматически. Не добавляйте серверные права игровым ролям: бот откажется их выдавать. `/автороли включить:False` приостанавливает изменения, сохраняя уже выданные роли.

Личный опыт участника и общий опыт питомца считаются отдельно. Игровые награды ограничены 300 монетками и 200 XP за сутки по `TZ`; ежедневный визит и одобренное задание начисляются отдельно. Наград за количество сообщений нет. Все игры бесплатны, проигрыш не отнимает накопленные монеты. Подробный баланс — `DESIGN.md`.

## Данные и надёжность

- База и вложения заявок: `data/` либо папка, заданная через `DATABASE_PATH`. Для резервной копии остановите бота и скопируйте всю папку данных, затем запустите снова.
- Панель, уход, новые события и новые мини-игры сохраняют работоспособность кнопок после перезапуска, пока не истёк срок игры. Личные викторины версии 2.1 сохраняются; незавершённые дуэли нужно открыть заново.
- Награда за событие фиксируется вместе с попыткой одной транзакцией. Повторный клик, другой канал или другой сервер не дают повторную выплату.
- После простоя бот не публикует все пропущенные события. При неопределённой ошибке отправки пропускает событие, чтобы не дублировать сообщение.
- Очередь ролей сохраняется и повторяет временно неудачные операции. Обычно роль обновляется в течение минуты; для большой очереди или ошибок прав требуется больше времени. `/роль` позволяет проверить выдачу сразу.
- Одежда — цельные комплекты в игровых карточках. Аватар аккаунта при переодевании не меняется. Для сонного и голодного состояния используются отдельные рисунки.

## Проверки

В среде сборки прошли **45 тестов** и автономная проверка Discord-адаптера: 31 команда, постоянные кнопки, полное покрытие команд справкой и 16 файлов изображений. Проверены перенос старой базы, повторные и одновременные выплаты, перезапуск событий, время рыбалки, права и очередь ролей. Запуск на живом сервере Discord и развёртывание на хостинге в эту проверку не входят.

```bash
python -m unittest discover -s tests -v
python check_discord.py
```

| Проблема | Что проверить |
|---|---|
| Нет новых команд | Обновлён `bot.py` и добавлен `features.py`, бот перезапущен, прежний `GUILD_ID` сохранён; проверьте лог синхронизации |
| Роли не выдаются | `/роли_настроить`, Manage Roles, положение роли бота выше рангов; затем `/роль` |
| Нет событий | `/настройка`, `/события включить:True`, тихие часы, права отправки в канале; для проверки `/событие` |
| Не видно новых кнопок | Опубликуйте `/панель` заново |
| Награда 0 или меньше указанной | Дневной игровой лимит |
| Нет изображения | Все 16 PNG находятся в `assets/`, разрешены Attach Files и Embed Links |

Код разделён на `bot.py` (старые команды и панели), `features.py` (новые Discord-функции), `game.py` (основная экономика), `activities.py` (события и очередь ролей), `content.py` (ранги, цены и контент).

## Изменения версии 2.1

- 60 вопросов: 30 прежних и 30 новых тематических вопросов/задачек. Новые темы: Dota 2, Hearthstone, RDR 2, кооперативные игры и авторские сценарии в духе «Бункера». Вопросы не привязаны к меняющимся ценам предметов или балансу карт; числа в задачках заданы прямо в условии.
- `/викторина`: максимум 3 открытия в календарный день по TZ, между открытиями 10 минут. На ответ 45 секунд. Пропуск и тайм-аут расходуют вопрос. После исчерпания банка повторы не включаются; другие игры продолжают работать.
- Личные и общие викторины используют одну историю: уже открытый лично вопрос не приносит повторную награду в общей игре. Общие вопросы не повторяются на сервере и исключаются из будущей личной выдачи даже тем, кто мог пропустить публикацию. Бот не может определить, кто просто прочитал сообщение.
- История и ограничения сохраняются в базе, перезапуск не сбрасывает их. Старые общие викторины версии 2 импортируются из сохранённых событий. **Истории личных вопросов до версии 2.1 не было — восстановить её невозможно.** Защита личных вопросов начинает действовать с этого обновления.
- Когда общие вопросы закончатся, часовые события продолжатся в виде заначки и «Поймай пакость». Ручной выбор викторины сообщит, что новых вопросов нет.
- Вопрос считается зарезервированным до отправки сообщения. При неопределённой ошибке доставки он также остаётся использованным: это предотвращает повторную выдачу после сбоя.
- `/байка`: 10 выдуманных историй про Dex, Kadi, RobedBroom и Мразика, без наград и пингов. Имена — часть художественных сцен, роли и привилегии этим участникам не добавляются.
- `assets/beach.png`: исправлен прозрачный фон; теперь тёплый серо-бежевый фон и тень, как у других образов.
- Проверено 45 тестами и автономной проверкой 31 команды и 16 PNG. Проверка не подключается к Discord; на хостинг этот комплект автоматически не установлен.
