# Мразик 3 — личные питомцы «Мразотного Логова»

У каждого участника свой Мразик: независимые сытость, настроение и энергия, свой опыт, монеты и гардероб. Discord-роль владельца определяется опытом его питомца. Все публичные игры и автоматические события идут только в выбранный игровой канал.

**Обновление работающего бота:** `UPGRADE.md`. **Отдельный чат и права для ролей:** `DISCORD_SETUP.md`.

## Сохранение прогресса

Версия 3 сохраняет прежние личные XP, монеты, купленные и надетые костюмы, настройки и ID игровых ролей. При первом переходе создаются отдельные состояния питомцев; прежний общий опыт не раздаётся каждому игроку. Повторный запуск не переносит данные заново. Перед миграцией существующих участников создаётся SQLite-копия в `backups/` рядом с базой.

Для сохранения после деплоя хостинг должен сохранять папку данных. Имя **`data/gnid.sqlite3`** оставлено прежним специально. Не меняйте `DATABASE_PATH` и не заменяйте базу пустой. Внешняя резервная копия папки данных нужна перед обновлением. Правила для дальнейших изменений кода находятся в `AGENTS.md`.

## Что умеет бот

- 31 команда и постоянная панель с кнопками «Мой Мразик», «Все команды» и «Больше игр».
- 12 образов для гардероба и 4 изображения состояний. Переодевание через `/гардероб` или `/одеть` влияет только на своего питомца.
- Шесть ролей за опыт питомца. Настройка один раз через `/роли_настроить`, проверка `/роль`.
- Викторины, дуэли, экспедиции, сундуки, угадайка и рыбалка.
- 60 вопросов и задачек, включая Dota 2, Hearthstone, RDR 2, кооп и сценарии бункера. История личных вопросов не сбрасывается: пауза 10 минут, до 3 открытий в день, 45 секунд на ответ. Исчерпанный банк автоматически не повторяется.
- Случайные общие события примерно раз в час: викторина, заначка или «Поймай пакость». Каждый может получить одну попытку, повторная награда за знакомый вопрос не выдаётся. При исчерпании общих вопросов остаются кликалки. Тихие часы и выключение — `/события`.
- 14 творческих заданий, проверяемых модератором, рейтинги, добровольные звания и 10 выдуманных баек с Dex, Kadi и RobedBroom.

Правила экономики и переноса — `DESIGN.md`. Источники тематических вопросов — `CONTENT_SOURCES.md`.

## Настройки

```dotenv
DISCORD_TOKEN=ваш_токен
GUILD_ID=ID_сервера
TZ=Europe/Moscow
DATABASE_PATH=data/gnid.sqlite3
```

На хостинге оставьте прежние переменные окружения. При локальном запуске скопируйте `.env.example` в `.env`. Настоящий токен и базу в GitHub не публикуйте. Главный файл — `bot.py`, Python 3.11 или 3.12, зависимости в `requirements.txt`.

Если создаёте нового бота: [Discord Developer Portal](https://discord.com/developers/applications), установка на сервер со scopes `bot` и `applications.commands`. Бот работает через Gateway, Interactions Endpoint URL не заполняется. Привилегированные Message Content, Members и Presence Intents не требуются.

`GUILD_ID` оставьте таким же, как до обновления. Пустое значение регистрирует команды глобально; указанный ID — для одного сервера. Не переключайте эти способы без необходимости.

Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe check_discord.py
.\.venv\Scripts\python.exe bot.py
```

Linux/macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python bot.py
```

Docker после заполнения `.env`:

```bash
docker compose up -d --build
docker compose logs -f
```

В комплектном Compose `data/` смонтирована с хоста. Запускайте один экземпляр на одном токене.

## Быстрый старт в Discord

1. Создайте `#мразик`, разрешите боту видеть канал, писать, встраивать ссылки, прикреплять файлы и читать историю.
2. `/настройка канал:#мразик` → `/панель` в этом канале.
3. Для ролей: право бота «Управлять ролями», его роль выше игровых рангов → `/роли_настроить`. Если роли уже настроены, повторно создавать их не нужно.
4. Игрок открывает `/мразик`, получает `/ежедневно`, ухаживает и играет; опыт идёт его питомцу. `/роль` проверяет Discord-ранг.
5. `/событие` запускает общее событие сейчас; `/события` управляет расписанием и ночной паузой.

До настройки канала игры не публикуются. В других каналах бот отвечает на игровые команды приватным перенаправлением. Административные команды и справка также могут отвечать приватно вне игрового канала. Обычные сообщения участников бот не читает и за их количество не награждает.

## Проверки и ограничения

Прошли **49 тестов**: миграция и повторный запуск, разделение питомцев, сохранение опыта/костюмов/ролей, ограничения наград, история вопросов, одновременные запросы и SQLite-backup. Автономная проверка охватывает 31 команду, 16 PNG, личные карточки, постоянные кнопки и ограничения канала. Живой Discord и деплой не входят в эту проверку.

```bash
python -m unittest discover -s tests -q
python check_discord.py
```

Постоянные кнопки питомца и новые викторины/мини-игры переживают перезапуск до истечения срока события. Дуэли после перезапуска нужно открыть заново. Истории личных вопросов до версии 2.1 не существовало, восстановить её нельзя.

Костюмы — цельные рисунки в карточках. Аватар Discord-аккаунта не меняется при переодевании. Старые сообщения с надписями об общем питомце автоматически не переписываются: опубликуйте новую `/панель`.
